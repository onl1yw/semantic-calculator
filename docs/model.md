# Модель и словарь

[← Semantic Calculator](../README.md)

## Источник

Приложение использует готовые веса **Word2Vec Continuous Skipgram**:
`ruwikiruscorpora_upos_skipgram_300_2_2019` из RusVectōrēs / NLPL.

| Параметр исходной модели | Значение |
| --- | --- |
| Модель в репозитории NLPL | 182 |
| Корпус | Национальный корпус русского языка и русская Википедия за декабрь 2018 года |
| Исходный словарь | 248 978 записей |
| Размерность | 300 |
| Окно контекста | 2 |
| Разметка частей речи | UPoS |
| Фильтр приложения | `NOUN`, 57 568 записей |

Источники: [каталог RusVectōrēs](https://rusvectores.org/ru/models/) и
[оригинальный архив с метаданными](https://vectors.nlpl.eu/repository/20/182.zip).
Автор в `meta.json` — **Andrey Kutuzov**. Модель опубликована в NLPL Word
Vectors Repository 2.0 в декабре 2019 года. Каталог RusVectōrēs указывает
лицензию **CC BY** для моделей. Оригинальные `meta.json` и `README` сохраняются
рядом с подготовленным словарём; атрибуция также записывается в его manifest.
Условия модели относятся к её весам и производным данным.

## От векторов к словам

Word2Vec представляет слово через контексты его употребления. У похожих слов
часто оказываются близкие направления векторов, а некоторые отношения между
понятиями выражаются похожими смещениями.

Перед использованием векторы слов нормализуются до единичной длины. Затем
калькулятор выполняет покомпонентную арифметику. В примере:

```text
r = v(король) − v(мужчина) + v(женщина)
```

Для поиска нормализуется копия `r`, после чего вычисляется косинусная близость
со всеми кандидатами. Исходные слова выражения исключаются из кандидатов.
В текущем словаре ближайшее слово — **«королева»**, близость около **0.7523**.
На экране она отображается как **75,2%**.

Полный вектор `r` остаётся текущим результатом. Следующее действие продолжает
арифметику с этим вектором. Ручной ввод «королева» выбирает самостоятельный
словарный вектор этого слова.

## Границы словаря

Для базовых подсказок, ввода и поиска сохранены только записи с тегом `NOUN`.
В исходном словаре это, например, `король_NOUN`; интерфейс показывает `король`.
Собственные имена с тегом `PROPN` и другие части речи в базовый набор не входят.
Личные определения дополняют словарь в браузере.

Ответы зависят от обучающего корпуса и фильтра кандидатов. Покомпонентное
умножение и деление доступны для экспериментов; у них нет заранее заданной
языковой интерпретации. Косинусная близость описывает положение векторов в модели.

## Подготовка данных

```bash
.venv/bin/python scripts/prepare_model.py
```

Импортёр скачивает официальный архив в `models/`, читает бинарный `model.bin`,
отбирает существительные и создаёт `data/dictionary-word2vec-nouns/`:

| Файл | Назначение |
| --- | --- |
| `words.json` | Словарь в порядке строк матриц |
| `raw_vectors.npy` | Исходные векторы существительных, Float32 |
| `vectors.npy` | L2-нормированные векторы для вычислений и поиска |
| `dictionary.sqlite3` | Исходные векторы и индексы строк для проверки и воспроизводимости |
| `manifest.json` | Источник, ревизия, размерность, количество и SHA-256 файлов |
| `source-meta.json`, `source-README.txt` | Оригинальные метаданные и атрибуция |

Подготовка сохраняет исходные значения векторов. Повторный запуск проверяет
хеши архива и подготовленных файлов. Ревизия включает преобразование L2 и фильтр
`NOUN`, чтобы состояния разных вариантов данных не смешивались.

В runtime нужны `manifest.json`, `words.json` и `vectors.npy` — около 71 МБ.
Матрица читается через read-only memory map. Контейнер проверяет SHA-256 словаря
и матрицы при запуске; подсказки, векторы слов и точный поиск используют только
эти локальные файлы. Облачная база не нужна. Подробнее — в
[инструкции развёртывания](deployment.md).

Все архивы, матрицы и локальные базы исключены из публичного репозитория.
